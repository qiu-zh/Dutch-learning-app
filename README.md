# DutchDeck Studio

A true installable Progressive Web App for Microsoft Edge. No Node.js, npm, API key, or subscription is required.

## Windows
1. Extract the ZIP.
2. Double-click `start-windows.bat`.
3. Edge opens at `http://localhost:8765`.
4. Click **Install app** or use Edge → Apps → Install DutchDeck Studio.
5. Keep the PowerShell window open while using the app locally.

## Import format
Paste lines such as:

`aanraden — to recommend — Ik raad je aan om vroeg te beginnen.`

The importer also accepts pipe, tab, semicolon, CSV, TSV, TXT, and DutchDeck JSON.

Your cards, settings, notes, favorites, and review history stay in browser local storage.
